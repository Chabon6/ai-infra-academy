# AI Infra 圖解學院

透過圖解、詞典與 3D 模型，認識 AI 基礎建設、晶圓製程及成本概念。

- [AI 基礎建設](https://chabon6.github.io/ai-infra-academy/)
- [台積電製程與成本](https://chabon6.github.io/ai-infra-academy/tsmc-cost/)

## 怎麼使用

從任一篇入口開始，依頁面段落閱讀，並開啟名詞說明、來源與延伸內容。

- 在手機上，先滑動閱讀；點「操作 3D」後可用單指旋轉模型、雙指縮放，點「完成操作」即可恢復滑頁。
- 點選模型部件或部件按鈕，可閱讀用途與相關說明；手機會在底部解說面板顯示內容。
- 透過詞典查找名詞與縮寫。AI 基礎建設篇收錄 31 組名詞；製程與成本篇收錄 62 個條目。
- 成本試算可調整產量、良率、固定成本與變動成本。手機版另可直接輸入數值，查看結果變化。

## 內容範圍

**AI 基礎建設**說明從晶圓、先進封裝、記憶體、載板、PCB、網路、供電到液冷的角色與關聯，並以互動模型輔助理解。

**台積電製程與成本**介紹製程、材料、設備、廠務與成本會計概念，包括資本支出、在製品、折舊、成本池、標準成本、良率及委外等主題。

3D 模型與互動情境皆為教學示意，不代表實際產品比例、設備光路、廠房配置、生產配方或商業流程。

## 資料來源與使用限制

資料查閱日為 2026-09-08。內容主要參考台積電公開年報與技術資料、NVIDIA、ASML、Lam Research、Merck、Entegris、KLA 等原廠公開資料，以及相關公司公開產品資訊；會計概念參考 IFRS Foundation 與 IAS 2 相關原則。各頁的來源連結可供進一步查閱。

文中列舉的公司僅代表其公開產品或服務領域，**不表示其為特定平台、製程節點或台積電的已驗證供應商**。

成本試算與交易情境均為教學假設，並非台積電的實際成本、內部科目、報價或財務預測；也不構成投資建議。技術路線圖與產品計畫應以原廠最新公開資訊為準。
